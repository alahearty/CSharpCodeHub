================================================================================
HOW TO VIEW DIAGRAMS
================================================================================

1. Online Viewer:
   - Visit: http://www.plantuml.com/plantuml/uml/
   - Copy the .puml file content
   - Paste and view the diagram

2. VS Code:
   - Install "PlantUML" extension
   - Open .puml files
   - Preview with Ctrl+Shift+P > "PlantUML: Preview Current Diagram"

3. IntelliJ IDEA:
   - Install PlantUML plugin
   - Open .puml files
   - Right-click > "PlantUML" > "Preview Diagram"

4. Command Line:
   - Download PlantUML jar from: https://plantuml.com/download
   - Run: java -jar plantuml.jar *.puml
   - Generates PNG/SVG files

================================================================================
DIAGRAM NOTATION
================================================================================

Class Diagrams:
- + : public
- - : private
- # : protected
- {readonly} : read-only property
- {abstract} : abstract method/property
- <|-- : inheritance
- <|.. : implementation
- --> : association/dependency

Use Case Diagrams:
- Actor : External entity
- Use Case : System functionality
- <<include>> : Required relationship
- <<extend>> : Optional relationship
